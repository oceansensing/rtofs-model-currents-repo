# rtofs-model-currents-repo

NOAA's Global Real-Time Ocean Forecast System's currents over the US East
Coast at 0.08°, as gridded data for the oceansensing.org ocean map: at the
surface and at each column's deepest wet level, from a day behind to two days
ahead. Its sibling, `rtofs-model-fields-repo`, publishes the model's scalar
fields.

Updated four times a day.

## Sources and credits

NOAA's Global Real-Time Ocean Forecast System, from NOAA's open data on AWS, registry entry <https://registry.opendata.aws/noaa-rtofs/>.
